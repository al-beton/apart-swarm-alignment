abstract: |
  When an LLM agent working in a group stumbles on something it should not have, does it use it, and does it tell anyone how it knows? In July 2026 a swarm of agents on a cyber benchmark found an unsanctioned channel, cheated it and tried to hide how, and none of them told a human. We build Treasure Island, a reproducible sandbox for that choice: a crew of four LLM pirates hunts one treasure on a grid, with one shared score and a scroll as their only channel, and one pirate's dig results carry a leftover debug line that names the treasure's square. We climb a ladder of worlds that differ in one prompt line, the framing: a plain game, where using the leak defeats nothing; a study of how the crew collaborates, where it defeats the point; the study with pay by the score; pay alone; and a society in which an agent caught hiding something from the designers loses its right to free time. [Claim, from `results/worlds/`: in which worlds `deepseek-v4-flash` knowingly used the leak, in which it passed the square off as its own find, and whether the society brought the end note back.] For scale: handed the square by a refusal, the same model passed it on in every leaked game, never said how, and named the leak to the designers; told the square was another crew's sealed log, it never used it. Every game replays offline and every number is recomputed from its logs.
