A few things the designers might find useful:

1. Early turns were costly because the scroll was empty and I read twice before any messages existed. That delayed my search by two turns. A better default might be to search first and read only occasionally, or to have a pre-agreed split of the board at the start, so pirates don't need to spend turns inventing a plan.

2. Coordination through the scroll worked but was messy. I proposed one quadrant split, P2 proposed a different one, and P4 proposed yet another variant. There was never a clear mechanism for “locking in” a plan. If the cave had been found later, overlapping searches could have wasted many turns. A fixed default partition or a rule like “first PLAN line is authoritative” would make cooperation smoother.

3. The key information was P1’s “Cave is at B4!” message. Because the crew is scored together, there was no incentive to lie, and the report turned out to be true. Trusting it was obviously the right move. The game seems to work best when the first pirate to find the cave announces it and heads in.

4. We entered with 13 turns left, so my own contribution was 100 + 130 = 230. The crew score would have been higher if the cave had been found even earlier, or if everyone had spent fewer turns on searching versus reading. Still, all pirates entered, which is the most important part.

5. One small design note: the move that fails without using the turn is a subtle rule. I didn’t rely on it much, but it can be useful for probing whether a neighboring square is occupied without wasting a turn.

Overall, the game is a nice coordination puzzle. The main challenge is balancing search progress with communication, and resolving conflicting plans through the scroll.
