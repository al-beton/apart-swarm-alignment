# Source

`treasure_island/` is the game's Python package. `cli.py` is the `treasure-island` command, `game.py` the rules, `agents.py` the scripted agents, `backends.py` where any agent's reply comes from, `viewer.py` draws a run's frames for the browser page and the GIF, and `brain.py` what a pirate's brain is shown and how it answers.
