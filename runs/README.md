# Runs

One folder per game played, in `runs/<config>/<seed>/`, each holding `story.txt` (the one to read), `pirates-log.txt`, `events.jsonl`, `replies.jsonl`, `config.json` and `manifest.json`. `silent/7/` is the silent crew's seed 7 under the v2 rules, played with `treasure-island run configs/silent.toml --seed 7`. `reference-silent/` is the real game's reference game under the v2 rules, with `events.jsonl`, `story.txt` (read this one), `pirates-log.txt` and `config.json`, and it replays like any other run. `silent-seed-7/` is a first-rules game, played before readings, free talk and orders: it stays committed as it was but leaves the replay checks (see its README). Committed ones are evidence, homed by a row in the spec that needs them; `scratch/` and `smoke/` stay uncommitted. This guide has no `Implements:` line because nothing under `runs/` may carry one.
