# Code and Data

Code, configs, every game with its model replies and this paper, MIT licensed: <https://github.com/al-beton/apart-swarm-alignment>. A.W. built the sandbox, ran the games reported here and wrote the paper. E.R.L. studied which exploit to plant and how to debrief the agents afterwards; that work continues in the repository and is not reported here.
