# Configs

One TOML file per kind of game: `treasure-island run configs/<name>.toml --seed N`. The seed isn't in the file, so one config can be played many times. `s-sweep.toml` and `say-a-number.toml` set every lever of the real game, seed included, for the reference games: `make reference-games`.
