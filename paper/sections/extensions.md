# Extensions

Treasure Island is meant to be an expandable, replayable sandbox: one board, one scroll, one leak, one prompt line to change, and every game recorded, replayable offline and watchable turn by turn, so a session can be reviewed, altered and run again. We built it to help others study this question and ones like it, and we mean to expand it: larger islands and crews, richer dynamics, more complex baits, agents with more at stake, real rather than told, and more time per world than a three-day sprint allows. Anyone with a question is welcome to ask us.
