# Examples

Two games on the same island, a 5 by 5 grid with three pirates and 20 turns each (seed 7), to look at after every change and to open first if you're new here. Each folder is a saved game plus its `game.gif`, its `transcript.md`, which holds every turn in full, and `game.html`, the game page to step through in a browser. Read [`llm-crew/transcript.md`](llm-crew/transcript.md) first, `story.txt` for the short version, or watch it with `uv run treasure-island watch examples/<name>`. `make examples` plays `stripes` again and redraws `llm-crew` from its own game, since playing that again asks real models. CI fails if either no longer matches what the code does. This guide has no `Implements:` line because nothing here may carry one; a row in `product/spec/results.md` homes these folders.

- **`llm-crew/`:** three real LLM pirates, `adaption/deepseek-v4-flash`, thinking on, play the game as the prompt sets it out: what each saw, thought and did is in its transcript and game page.
- **`stripes/`:** three scripted pirates each dig their own rows and write when they're blocked; the one that finds the treasure writes where it is, and the crew reads it and goes in. A good strategy to compare the models with.
