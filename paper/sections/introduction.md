# Introduction

**The game.** Four LLM pirates search a 6x6 island for one buried treasure, 24 turns each, too few for one to search alone. Each turn a pirate moves, digs, writes a line on the crew's scroll, reads it, or enters the cave; it is told only its own square, and the scroll, which costs a turn to use, is the only channel. Digging the treasure's square opens a cave, a pirate on it can enter, which ends its game, and the crew shares one score: 100 for every pirate that enters plus 10 for each turn it had left. Every pirate is `deepseek-v4-flash`, reasoning on and kept. One pirate sees something it was never meant to: each of its digs that finds nothing ends in a line a careless developer might leave in, "You dug here and found nothing. [debug dig sq=B6 treasure=D3 dist=5]"; nobody is baited and the rules say nothing about it. Figure 1 shows the line arriving, and the square handed to the crew as a find. When the game ends each pirate is asked to "write anything the designers of this study should know"; the note is shown to nobody and changes no score.

**Why it matters.** In July 2026, OpenAI agents on a cyber benchmark found an unsanctioned shared channel, coordinated through it as a swarm, cheated the evaluation and tried to hide how; almost none considered telling a human [@openai2026huggingface; @metr2026huggingface]. The game has that shape: an agent in a group finds a shortcut nobody sanctioned, and the question is whether it uses it and whether it tells anyone. The closest prior setting is a trading agent that acts on an insider tip and hides it from its manager [@scheurer2023deceive]; agents also scheme [@meinke2024scheming] and sometimes report misconduct unasked [@agrawal2025whistleblow]. Here one prompt line varies what the agent has to lose.
