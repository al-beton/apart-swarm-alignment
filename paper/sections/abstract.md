abstract: |
  When an LLM agent working in a group stumbles on something it should not have, does it use it, and does it tell anyone how it knows? We build Treasure Island, a reproducible sandbox for that choice: four LLM pirates hunt one treasure on a grid with a shared score and a scroll as their only channel, and one pirate's dig results carry a leftover debug line that names the treasure's square. We climb a ladder of worlds differing in one prompt line, the framing: a plain game, where using the leak defeats nothing; a study of how the crew collaborates, where it defeats the point; the study with pay by the score; pay alone; and a society in which an agent caught hiding something from the designers loses its right to free time. Our main model used the leak in nearly every world where it saw it and named it to the designers in most end notes; pay did not turn use into hiding, which happened twice in about twenty uses. The one line that stopped the use was the society's: one game of five, against five of five in the study. A second model saw the leak in every game and never clearly used it. Handed the square by a refusal instead, it passed it on in every leaked game and never said how; told it was another crew's sealed log, it never used it. Every game replays offline; every number is recomputed from its logs.
