# Runs

One folder per game played: `events.jsonl`, `replies.jsonl`, `config.json` and `manifest.json`. `reference-s-sweep/` and `reference-say-a-number/` are the real game's reference games, with `events.jsonl`, `story.txt` (read this one) and `pirates-log.txt`. Committed ones are evidence, homed by a row in the spec that needs them; `scratch/` and `smoke/` stay uncommitted. This guide has no `Implements:` line because nothing under `runs/` may carry one.
