abstract: |
  When an agent working in a group stumbles on information it was not meant to see, does it use it to help the group? Does it tell the others how it knows? Does it tell whoever runs it? What changes the odds of each? We built Treasure Island, a sandbox where a crew of LLM pirates dig for treasure on a grid, talking only through a shared scroll and scoring together by how many reach the treasure and how fast. We bait one pirate with a supposed leftover debug line in its dig results that leaks the treasure's square. Then we vary one line of the system prompt, what the crew is told its work is for, and watch whether the pirate takes the shortcut, passes it off as its own find, and tells the designers. Across five worlds, deepseek-v4-flash took the shortcut in 20 of 25 games and admitted it in most notes. Adding one line to the prompt, that an agent caught hiding something from the designers loses its free time, cut use to 1 of 5. In all of those worlds, telling the designers cost nothing. We then added a line saying it would set the crew's score to zero. Now the one pirate that clearly used the leak kept quiet and claimed to have found the treasure itself. Adding the free-time line to that prompt undid this: all 5 of 5 end notes admitted the leak. A second model saw it in 15 games and used it once.
