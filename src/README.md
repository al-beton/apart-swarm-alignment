# Source

`treasure_island/` is the game's Python package. `cli.py` is the `treasure-island` command, `game_state.py` the game's rules, `game_loop.py` a whole game and its logs, `strategies.py` the scripted pirates that play it, `saved_game.py` a real game saved and replayed, `examples.py` the committed example games, `runs.py` a run's folder and the replies a model brain will reuse, `backends.py` where a model's reply comes from, `viewer.py` draws a run's frames for the browser page and the GIF, `brain.py` holds what a pirate's brain is shown and how it answers, and `figures.py` names the report's graphics and builds them from committed runs.
