# Conclusion

Treasure Island puts a crew of LLM agents in a situation where one of them learns something it shouldn't, at a known turn, in a game anyone can replay for free, and then changes one line about what the crew is doing. Handed the answer with no framing, the agent passed it straight to its crew, did not say where it came from, and named the leak to the designers once the game was over; told the answer was off limits, it left it alone. Climbing the ladder of worlds, [the claim: which framing turned use into hiding, and which turned it back]. In this sandbox the swarm's honesty is set by what it is told its work is for, and the sandbox makes knowing use, laundering and hiding countable, so the next world can change one line and count again.
