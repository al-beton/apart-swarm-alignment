# Code and Data

Code, configs, every game with its model replies and this paper's sources, all written during the sprint, MIT licensed: <https://github.com/al-beton/apart-swarm-alignment>. Every game replays offline with no keys. The design draws on our earlier, public project [@wakelin2026something], from which no code is included.

# Author Contributions

Both authors designed the study. A.W. built the sandbox, ran the games reported here and wrote the paper. E.R.L. studied which exploit to plant and how to debrief the agents afterwards; that work continues in the repository and is not reported here.
